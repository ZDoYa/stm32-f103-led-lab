STM32_点亮与心跳工程记录报告
工程概况：这周我让板载LED按500~100ms闪烁，并读出了时钟树三格数。
工程过程：我首先用了【STM32cubeMX】进行工程的创建，具体涉及芯片引脚的选择与时钟的设置，在时钟树里设置时钟频率与分配。然后我将工程创建好后便开始代码的生成，用【STM32cubeIDE】打开并写入代码。我在main函数中写入了while循环语句“while (1)
{
	HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);
	HAL_Delay(500);
}”,这是让LED灯按500ms闪烁的指令。之后编译代码，无报错后烧录进开发板，运行，LED能按照500ms正常闪烁。之后，我尝试将500ms改为100ms闪烁，重新编译烧录运行，可见灯的闪烁频率明显变快了。
遇到的困难：过程中，因硬件的区别，我纠结引脚的选择，与视频的讲解有所差别，最终开通了PA0引脚设置GPIO_Output，关闭了RCC的HSE通道，使用内部时钟。然后在烧录过程中，ST-link连接识别报错，经逐步排查ST-link，排线，开发板后发现开发板出现了硬件性问题，更换开发板后才得以正常烧录。在LED连接过程中，因排线不熟练，导线接触不良，导致浪费了很多时间，但都靠视频讲解解决。
视频数据材料：三格数：系统时钟频率64MHz，HCLK设置64MHz，PCLK1设置32MHz。AHB Prescaler设置/1，APB1 Prescaler设置/2
下周想确认：时钟树中除了已接触的参数，其他的参数的意义还不是很明确，进阶的任务也还没开展，我的开发板的具体问题还没有找到，对一些名词的掌握还不深刻，排线的连接也还不熟练。
拯救措施：我在首次工程创建时使用了HSE，发现灯并不能闪烁，发觉我的开发板可能并没有焊晶振，便关掉了HSE，使用内部时钟。
在我创建好工程后烧录时，因发现了代码的一些问题紧急停止，用Reset键结合【STM32cubeProgrammer】清除了开发板缓存，重新烧录。
